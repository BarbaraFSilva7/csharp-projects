## 🔨 Projects Included 

### 1. Customer Satisfaction System
An interactive Console Application developed in pure C# to collect and analyze customer service feedback.

* **Where to find it:** Inside the `/CustomerSatisfactionSystem`folder.
* **Key Concepts Practiced:**
  * Flow control using `switch/case` to handle different feedback scores.
  * Professional  error handling with `default` for invalid inputs.
  * Interactive user experience via terminal using English phrasing.
  * Data input and output manipulation (`Console.ReadLine` and `Console.WriteLine`).
