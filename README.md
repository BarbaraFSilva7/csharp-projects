# C# Projects & Exercises 🚀

This repository was created to store my exercises, logic challenges, and mini-projects developed during my C# and .NET studies.

## 🔨 Projects Included 

### 1. Customer Satisfaction System
An interactive Console Application developed in pure C# to collect and analyze customer service feedback.

- **Where to find it:** Inside the `/CustomerSatisfactionSystem` folder.
- **Key Concepts Practiced:**
  * Flow control using `switch/case` to handle different feedback scores.
  * Professional error handling with `default` for invalid inputs.
  * Interactive user experience via terminal using English phrasing.
  * Data input and output manipulation (`Console.ReadLine` and `Console.WriteLine`).

---

### 2. Credential Validator
A Console Application built to demonstrate user access validation and permission rules using fundamental boolean logic operators.

- **Where to find it:** Inside the `/CredentialValidator` folder.
- **Key Concepts Practiced:**
  * Boolean data types (`bool`) for state tracking (`isLogged`, `hasAdminAccess`).
  * Logical `OR` (`||`) operator to evaluate system access conditions.
  * Logical `AND` (`&&`) operator for administrative access restriction.
  * Logical `NOT` (`!`) negation operator to verify authentication states.
  * Clean output formatting using console separators.
